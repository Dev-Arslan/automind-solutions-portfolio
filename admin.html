Edit the fields below, then click Generate. Copy the result and paste it over the contents of assets/config.json in your GitHub repo. Every page reads that one file, so this single edit updates your email, phone, WhatsApp, LinkedIn, GitHub, and location everywhere on the site — header, footer, contact page, and the floating WhatsApp button.

This page cannot save directly to GitHub for you. Doing that safely would require a GitHub access token embedded in the page — and since this is a public static site, anyone could view the page source and steal write access to your repo. Copy/paste into config.json is the safe way to do this on a plain GitHub Pages site.
